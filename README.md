# Netflix Website Copy

Recreation of Netflix India's landing, sign up and log in pages using plain HTML, CSS and JS.

- `index.html` – all three pages (landing, sign up, log in) in one file; JS switches views by URL hash (`#/`, `#/signup`, `#/login`)
- `style.css`, `script.js` – shared styles and client-side form validation (no backend)

Open `index.html` in a browser to run it. Responsive down to mobile widths.
